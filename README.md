# 🛒 FreshCart - Online Grocery Shop

FreshCart is a fully functional, responsive e-commerce web application designed to make online grocery shopping seamless, fast, and secure. Users can browse fresh produce, manage a dynamic shopping cart, schedule deliveries, and securely check out.

## ✨ Features

### 👤 Customer App
*   **User Authentication:** Secure signup, login, and logout using JWT and password hashing (bcrypt). Google OAuth integration.
*   **Smart Product Search:** Real-time search bar with auto-suggestions and filters based on categories (e.g., Fruits, Dairy, Bakery) or dietary needs (e.g., Organic, Gluten-Free).
*   **Persistent Shopping Cart:** Items remain in the user's cart across sessions. Real-time subtotal, discount, and tax calculations.
*   **Checkout & Delivery Scheduling:** Multi-step checkout with address saving and delivery time-slot selection (e.g., Same-day, Next-day morning).
*   **Payment Gateway Integration:** Secure payment processing simulation using Stripe/PayPal.
*   **Order Tracking:** Live order history dashboard displaying status updates (e.g., *Processing, Out for Delivery, Delivered*).

### 👑 Admin & Store Management Panel
*   **Inventory Control (CRUD):** Add, update, view, and delete products, update stock quantities, and upload product images.
*   **Low Stock Alerts:** Automatic dashboard notifications when product stock falls below a specific threshold.
*   **Order Fulfillment Dashboard:** Update delivery statuses and view sales analytics metrics.
